# Configuration

There is no config file in alpha. Every number lives in code next to the behaviour it tunes, and the picker copy is generated from those same numbers so documentation cannot drift from behaviour.

What this page will hold once knobs exist: file location, full field table with defaults, validation and backfill rules, and the gamerule/command equivalents where they apply.

Until then, balance and content tuning are out of scope for alpha success — crash-hunt plus core loop feel is the goal.
